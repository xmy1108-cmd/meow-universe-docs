# 喵宇宙 Meow Universe

**查生活大小事，找到可以採取的下一步。**

喵宇宙把分散的資料、實用工具與專業知識整理成垂直網站。你可以查附近診所、幼兒園、垃圾車與停車場，也可以做長照、赴日或投資研究的功課。各站專注一種讀者需求，共用資料來源規格、內容治理與逐步串接的會員服務。

## 已經做了什麼

- 已有公開營運目錄、作品集、官方驗證、共同會員入口與專家投稿。官方驗證快照列出 **7 站**，下方以「已驗證」標示。
- 已提供在地查詢與工具，從垃圾清運、停車、幼兒園、醫療照護到台美日股市研究。運動喵有匹克球場地專區，診所喵已有物理治療、心理諮商、護理及兒童早療入口的發版紀錄。
- 已建立共用資料、編輯、部署及搜尋品質工作流，並逐站推進標籤頁、主題叢集和版型更新。

## 接下來做什麼

1. 建立官方主站，讓讀者依需求找網站和工具、核對正式網域、看更新與回報資料錯誤。

3. 逐站擴充會員與收藏支援，建立可引用的公開研究、專家專區及資料合作入口。

- **[公園喵](https://parkmeow.com.tw/)**

- **[電費喵](https://powermeow.com.tw/)**

- **[回收喵](https://recyclemeow.com.tw/)**

- **[公廁喵](https://toiletmeow.com.tw/)**  
  出門臨時需要上廁所，或想先替小孩、長輩和輪椅使用者安排休息點，可以查附近公廁的位置與公開設施資訊。適合規劃親子行程、長程散步與陌生街區路線，出發前也能先看管理單位公布的開放時間。

- **[飲水喵](https://watermeow.com.tw/)**  
  走路、騎車或帶孩子出門，水壺喝完時可以查公開飲水機與直飲台的位置。站點整理部分縣市的公開點位及可取得的開放資訊，適合在城市散步、公園活動或戶外路線途中安排補水，也方便出發前先找備用點。

- **[天氣防災喵](https://weathermeow.com.tw/)** · 已驗證  
  規劃通勤、戶外活動或假日出遊時，可以依地點查看整理過的天氣預報與警戒資訊，先判斷降雨、高溫或風勢會不會影響行程。遇到颱風與劇烈天氣，可循站上的資訊回查氣象署及地方政府的最新發布。

- **[家事喵](https://houseworkmeow.com.tw/)**  
  碰到油垢、水垢、發霉或衣物污漬，可以依清潔情境找處理順序、常見材料的注意事項及清潔劑使用原則。適合想自己做日常維護、搬家前後打掃，或想先釐清表面材質和髒污種類，再選清潔方式的人。

- **[里長喵](https://villagemeow.com.tw/)**  
  想知道家裡屬於哪個里、里長或里辦公處怎麼聯絡，可以按縣市、行政區與里名查找。適合剛搬家的居民、想反映鄰里問題的人，以及查地方服務或選舉資訊的讀者，聯絡前也能回查地方政府公告。

### 交通出行（7）

- **[充電喵](https://chargingmeow.com.tw/)**

- **[日本交通喵](https://jptransitmeow.com.tw/)**  
  給準備去日本自由行的台灣旅客，整理機場進市區、地鐵、公車、新幹線與交通票券的查詢入口。從行李多時怎麼轉乘，到一日券、周遊券值不值得買，都可以先用行程比對，再去交通業者確認最新班次和票價。

- **[停車喵](https://parkingmeow.com.tw/)**  
  去車站、商圈或景點前，先查附近路外停車場的位置、費率與格位資訊。適合用來比較走路距離和預估停車成本，遇到假日熱門路段時也能先備第二方案。若有車高或停留時間限制，可在出門前一併核對。

- **[加油喵](https://petrolmeow.com.tw/)**  
  把加油站位置、油價與自助加油等資訊放在同一入口，方便通勤、跑長途或借車時先找順路的站點。平常也可以從省油與用車相關內容了解，不同路線、油品和加油方式會怎麼影響日常交通支出。

- **[物流喵](https://shipmeow.com.tw/)**  
  寄件前先弄清楚包裹尺寸、重量和寄送需求，再對照不同物流方式的費用、限制與適用情境。適合網拍賣家、需要寄行李的人，以及第一次處理大件或特殊包裹的讀者，先準備好會被物流業者問到的資訊。

- **[台灣交通喵](https://twtransitmeow.com.tw/)**  
  從台鐵、高鐵等跨城交通開始，查車站、路線、首末班和轉乘方式。適合規劃通勤、返鄉或帶家人出門，先想清楚在哪一站上車、要留多少轉乘時間，以及錯過預定班次時還有哪些公開交通選擇。

- **[科技執法喵](https://speedingmeow.com.tw/)**  
  把公開的固定測速、區間測速與闖紅燈科技執法資訊整理成可查的路段入口。開車到陌生地區前，可以先了解道路限速和常見設置情境，碰到修路或新設執法時，以現場交通標誌、標線及主管機關公告為準。
